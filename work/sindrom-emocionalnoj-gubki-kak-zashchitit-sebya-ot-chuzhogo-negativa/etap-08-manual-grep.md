# Этап 8: Ручной grep-аудит (Manual Grep)
Дата: 2026-08-16

```bash
# Grep на длинные тире:
$ grep -c "—" draft.md
0

# Grep на короткие тире (en-dash):
$ grep -c "–" draft.md
0

# Grep на запрещенные клише «в современном мире», «не секрет»:
$ grep -nEi "в современном мире|не секрет|давайте разберемся|как мы знаем" draft.md
(пусто)

# Grep на «Это не X. Это Y»:
$ grep -nP "Это не [^.]+\. Это" draft.md
(пусто)
```

Вердикт: Ручные grep-проверки пройдены успешно (0 нарушений).
